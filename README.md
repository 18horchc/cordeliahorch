# Academic personal site

A small static site (About / Publications / Blog / CV) styled with Tailwind CSS,
deployed via [GitHub Pages](https://docs.github.com/en/pages).

## Files

| File / folder        | Purpose                                                        |
| -------------------- | -------------------------------------------------------------- |
| `index.html`         | Home — short bio and affiliation                               |
| `publications.html`  | Publications list, grouped by year                             |
| `blog.html`          | Blog post archive                                              |
| `cv.html`            | Curriculum vitae                                               |
| `css/base.css`       | Tiny stylesheet for the skip-to-content focus state            |
| `.nojekyll`          | Tells GitHub Pages to serve the files as-is (skip Jekyll)      |

## Editing content

Open any of the four `.html` files in an editor and edit the text inside the
`<main>` block. Search-and-replace `Your Name`, `you@university.edu`,
`University Name`, etc. to fill in your details.

The brand palette and fonts are configured at the top of each HTML file inside
the `tailwind.config = { ... }` block — change the `brand.*` hex values to
re-skin the whole site at once.

## Local preview

Because the site is plain HTML you can just open `index.html` in a browser, or
serve the folder with any static server, e.g.

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Deploying

Push to the `main` branch of your GitHub repo. In **Settings → Pages**, set:

- **Source:** Deploy from a branch
- **Branch:** `main` / `(root)`

The site is rebuilt and republished automatically on every push.

## A note on Tailwind

Tailwind is loaded from the official Play CDN (`cdn.tailwindcss.com`) so there
is **no build step**. You will see a `cdn.tailwindcss.com should not be used in
production` warning in the browser console; it is harmless for a small personal
site. If you ever want to remove it, swap the CDN script for a precompiled
Tailwind stylesheet generated by the [Tailwind CLI](https://tailwindcss.com/docs/installation).
